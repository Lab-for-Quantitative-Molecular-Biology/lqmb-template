# LQMB project metadata

This directory records how the project relates to the LQMB template and other project dependencies.

- `project.json` — project identity and the exact LQMB template version/commit adopted.
- `dependencies.json` — declared software, project, dataset and publication dependencies.
- `manifest.json` — paths governed by the LQMB template and paths protected from template updates.

See `docs/lqmb/LQMB_LIVING_PROJECT_FRAMEWORK.md` for the framework and `docs/lqmb/TEMPLATE_UPDATE_PROTOCOL.md` for the update procedure.
