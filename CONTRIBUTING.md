# Contributing to LQMB projects

LQMB uses a contribution-oriented model. People contribute according to expertise, interest, and opportunity rather than fixed scientific hierarchy.

## Before contributing

- Read `CLAUDE.md`.
- Read the relevant project documentation.
- Check existing issues and pull requests.
- Do not add research data, secrets, or sensitive information to Git.

## Typical workflow

```text
issue / discussion
      ↓
branch
      ↓
implementation or analysis
      ↓
tests / validation
      ↓
pull request
      ↓
review
      ↓
merge
```

## Human responsibility

Every contributor is responsible for understanding and reviewing material they submit. AI assistance does not transfer scientific responsibility to the AI system.

## AI provenance

When Claude materially contributes to a commit or pull request, disclose this using the conventions in `AI_PROVENANCE.md`.
